# 💳 Credit Card Report | Data Analysis Project

## 📌 Project Overview

This project analyzes **credit card customer and transaction data** to identify spending patterns, customer behavior, revenue trends, and key business insights.

The project includes **data cleaning, data transformation, exploratory data analysis (EDA), KPI calculation, and data visualization** to convert raw data into meaningful and actionable insights.

## 🎯 Project Objectives

* Analyze credit card transaction data
* Understand customer spending behavior
* Identify revenue and transaction trends
* Calculate important business KPIs
* Explore customer demographics and card usage
* Identify patterns and trends in transactions
* Create clear and informative dashboards/reports
* Present data-driven business insights

## 🛠️ Tools & Technologies

* **Excel** – Data cleaning, analysis, and reporting
* **SQL** – Data querying and data analysis
* **Python** – Data analysis and automation
* **Pandas** – Data manipulation and analysis
* **NumPy** – Numerical analysis
* **Data Visualization** – Charts, graphs, and dashboards

## 🔍 Data Analysis Process

### 1. Data Collection

Collected and examined credit card customer and transaction datasets.

### 2. Data Cleaning

* Removed duplicate records
* Handled missing values
* Checked data types
* Standardized data
* Prepared data for analysis

### 3. Exploratory Data Analysis

Performed EDA to understand:

* Customer spending patterns
* Transaction trends
* Revenue distribution
* Card usage behavior
* Customer segments

### 4. KPI Analysis

Calculated key performance indicators such as:

* Total Revenue
* Total Transactions
* Total Customers
* Average Transaction Amount
* Customer Spending
* Revenue Trends

### 5. Data Visualization

Created visualizations and dashboards to communicate important findings and make the analysis easier to understand.

## 📊 Key Insights

The analysis focuses on identifying:

* Customer spending behavior
* Revenue-generating customer segments
* Transaction trends over time
* Card usage patterns
* Differences in customer activity
* Important business performance indicators
